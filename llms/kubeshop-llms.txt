# Kubeshop / Testkube

> Testkube is an open-core, Kubernetes-native test orchestration platform from Kubeshop. It runs
> agents inside Kubernetes clusters under a central control plane, orchestrating tests written for
> existing frameworks (Cypress, Playwright, k6, JMeter, pytest and others), then aggregates the
> executions, logs, artifacts, JUnit reports and flakiness metrics across environments and CI/CD
> systems. Testkube publishes three OpenAPI 3.0.1 documents, a first-party CLI, Helm charts, and a
> hosted Model Context Protocol server with 30 tools.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. Testkube does not publish its
own /llms.txt (docs.testkube.io/llms.txt returns 404), so this file is generated from the
provider's real published artifacts.

## APIs

- [Testkube Control Plane API](https://docs.testkube.io/openapi/cloud/Agent-Operations----executions): 108 operations. Manages
  organizations, environments, agents, members, teams, resource groups, credentials and audit
  logs, and proxies authenticated calls to connected environment agents. Base URL
  https://api.testkube.io. Bearer-token authenticated.
- [Testkube Standalone Agent API](https://docs.testkube.io/openapi/agent/default--triggers): 34
  operations. Programmatic access to the agent running in standalone mode — test workflows,
  executions, artifacts, webhooks and triggers.
- [Testkube API (open source)](https://github.com/kubeshop/testkube/blob/main/api/v1/testkube.yaml):
  74 paths covering the open-source surface — tests, executions, test suites, labels, artifacts,
  logs, executors, webhooks, webhook templates and test triggers.

## Conventions

- Authentication: bearer token, `Authorization: Bearer <API_TOKEN>`; tokens issued from
  Organization Settings → API Tokens. OAuth 2.1 applies to the MCP endpoint only.
- Errors: RFC 9457 `application/problem+json`; problem types namespaced under
  https://kubeshop.io/testkube/problems/
- Pagination: `pageSize` and `page` query params; RFC 8288 `Link` header plus a `Total-Count` header.
- Filtering: Kubernetes label-selector semantics via `selector`, `label`, `excludeLabel`, `textSearch`.
- Idempotency: not supported. There is no `Idempotency-Key` contract; execution-creating
  operations start a new run on every call.
- Plan gating: HTTP 402 signals a commercial feature requiring a Pro subscription (82 operations).
- Rate limiting: HTTP 429 on six organization/membership mutations plus an AI generation quota
  that reports `limit`, `used` and `resetsAt` in the problem body. No rate-limit headers.
